Spellforge

Procedural spell-icon compositor. Every icon is built from keywords at runtime: element → palette, form → glyph, modifier → overlay. No image assets — clouds, bloom, and color grading are generated in Canvas 2D.

Wild lightning strike

Same keywords + same seed always produce the same icon. Change one keyword and only its layer changes — the rest of the icon stays recognizable, which reads as intentional design.

Pipeline: noise clouds → lit by glyph → additive bloom (4 blur passes) → modifier overlay → vignette → gradient-map LUT → beveled rim.
