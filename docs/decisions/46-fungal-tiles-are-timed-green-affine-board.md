# Decision #46 — Fungal tiles are TIMED, GREEN-AFFINE board threats; the timer is encoded in the TYPE ID; relics can watch BOTH sides' events (anySide) — the Blight Warden engine (2026-07-10).

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Fungal tiles are TIMED, GREEN-AFFINE board threats; the timer is encoded in the TYPE ID; relics can watch BOTH sides' events (`anySide`) — the Blight Warden engine (2026-07-10).** New Act 1 minion **blight_warden** (floors 5-7, uncommon, HP 15 baseline, attack 2, no mana, standard AI — [`blightWarden.js`](../../src/js/data/enemies/act1/blightWarden.js)): hoards Green for **Blighted Growth** (6 green: create 6 Fungal tiles + extra turn, [`skillCatalog.js`](../../src/js/data/skills/skillCatalog.js); dedicated SFX `skill_blighted_growth`, and the explosion plays `sfx_fungal_explode` via the one-shot `getState().fungalExploded` flag — both sprite-backed clips) while **Vampiric Roots** ([`enemyRelicCatalog.js`](../../src/js/data/relics/enemyRelicCatalog.js)) heals it 1 HP per tile whenever ANYONE matches Green. Five reusable mechanisms:
- **Fungal tile types** ([`TileTypes.js`](../../src/js/game/TileTypes.js)): `FUNGAL_2`/`FUNGAL_1` (`isFungal: true, isInert: true`, spawnWeight 0, effect-only) — the remaining turn timer IS the type id (`fungalTimer` field + helper), so it rides gravity/swap/clone/shuffle with ZERO side-band board state (the lock-by-color lesson, applied per-tile). Helpers `isFungal(id)` / `fungalTimer(id)`. `isInert` keeps raw (non-match) destroys awarding nothing.
- **Green-affine matching** ([`BoardModel._scanLineRuns`](../../src/js/game/BoardModel.js)): fungal never forms its own scan class (both timer stages must intermatch without double-reporting) — every fungal cell joins the GREEN class as a CONCRETE member: it extends green runs, a pure-fungal 3+ run matches by itself, and wilds bridge as usual. **Every fungal match is emitted as typeId `'green'`** — so downstream (per-tile mana award, mana streams, onTileMatchType reactors, Vampiric Roots) sees a normal green match with zero MatchResolver changes. A locked green also locks fungal. Matching fungal therefore FEEDS the matcher green mana but heals the Warden — the fight's core "clear it and feed him, or leave it and eat skulls" tension.
- **Timer tick + explosion** ([`BattleController._tickFungalTiles`](../../src/js/game/BattleController.js), called from `_completeTurnIntro` when `side === 'enemy'`, AFTER the onTurnStart dispatch, guarded to no-op if a turn-start passive already entered RESOLVING): snapshots both stages first (aging never explodes same-tick), ages `fungal_2 → fungal_1`, and each expired `fungal_1` EXPLODES — Skull in place + `FUNGAL_SPREAD_PER_TILE` (2, named const) fresh `fungal_2` spread via safe-spawn placement (exponential growth if ignored; board size is the cap). New skull lines resolve as TURN SETUP via `_resumeTurnAfterResolve` (the Chokeweed Sap machinery — the enemy is the active side, so skull damage hits the player; no extra turn possible). All mutations surface through the existing `convertedTiles` shimmer (no new one-shot).
- **`anySide` relic effects** ([`PassiveSystem`](../../src/js/systems/PassiveSystem.js)): `dispatch` now runs a second pass over the OPPOSITE side's relics for effects flagged `anySide: true` (ctx.caster = the relic OWNER; the payload keeps the acting side for conditions). anySide effects should stay ATOMIC (board-touching handlers read `payload.side` as the actor). Plus **`heal.perCount`** ([`EffectResolver`](../../src/js/systems/EffectResolver.js)): multiplies a heal by the trigger payload's `count` ("heal N per tile matched").
- **Skill-path safe spawn**: `createTiles.avoidMatches` now also works on the SKILL create path ([`BattleController._executeCreateTiles`](../../src/js/game/BattleController.js) — one-at-a-time placement, same semantics as the passive path), and creating fungal never overwrites existing fungal (`_createTileCandidates`, shared by the skill / passive / explosion placement). **UI:** [`BoardPlaceholder`](../../src/js/ui/BoardPlaceholder.js) draws a turns-remaining number badge (top-right corner, `_drawFungalTimerBadge`, also on swapping tiles) derived purely from the type id; both stages alias to the `green_blight_tile` sheet sprite (`tile_fungal_2`/`tile_fungal_1` in [`main.js` ASSET_ALIASES](../../src/js/main.js); portrait alias `portrait_blight_warden`). `[[Fungal Tiles]]` keyword in [`keywordDefinitions.js`](../../src/js/data/keywordDefinitions.js) (aliases: fungal, fungal tile).
- **Sim parity (mirrored 2026-07-10):** `sim/toolbench/engine.mjs` now mirrors the full engine — `_passivesFor` anySide second pass, `heal.perCount`, `_tickFungal` at the enemy's `_turnStart` (after onTurnStart passives; explosion cascade resolves via `suppressExtraTurn`), and the shared `_placeTiles` placement (one-at-a-time avoidMatches on BOTH skill + passive create paths, fungal-on-fungal exclusion) — with the mirrored constant `FUNGAL_SPREAD_PER_TILE` (2) guarded by `drift-check.mjs`. **The formula evaluator ([`ai/formulaPolicy.js`](../../src/js/game/ai/formulaPolicy.js)) gained two fungal-aware weight keys** (CEM genome grew — pre-2026-07-10 weight JSONs load but are stale for these): `fungalClear` (value per fungal tile an action removes — `settleBoard` now reports `fungalCleared` + per-type `matchedByType`; destroy paths count direct clears too) and `oppMatchHeal` (penalty × HP the opponent heals from YOUR matches, derived generically from `opp.relics` anySide match-heal effects, clamped to missing HP — raw destroys don't trigger match heals, making destroy skills the clean blight counterplay). The INPUT CONTRACT gained optional `relics` on combatants (`_makeHintFacade` passes them; the sim Battle always had them). `features.mjs` `TILE_INDEX` still doesn't know the fungal ids (affects learn/collect only). **Champion RETRAINED + PROMOTED 2026-07-10** (seeded CEM, 24 gens, run-survival): fresh-seed tournament (ns `fungal-final-2026-07-10`) challenger 40.0%±1.7 vs incumbent 33.3%±1.7 (defaults 25.6%, greedy 0.6%) — absolute survival reads lower than the old ~45% because the WORLD got harder (Blight Warden), not the policy weaker. `train.mjs` now checkpoints `<out>.ckpt.json` every generation. ⚠ Blight Warden measured OUT OF BAND under the greedy bracket: 59% (f5) / 44% (f8) player win vs the 85-95% minion band, burst 44-51% — needs a tuning pass (levers: the 7-damage rider's `_100` scaling, `FUNGAL_SPREAD_PER_TILE`, Roots heal rate).
