# Decision #11 — Enemy HP AND attack scale per floor in MapScene

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Enemy HP AND attack scale per floor in MapScene** ([`_transitionToBattle`](../../src/js/scenes/MapScene.js)): each enemy's `maxHp`/`attack` in the data files is a **floor-1-equivalent baseline**. **HP** is multiplied at spawn by `ENEMY_HP_FLOOR_MULT[node.depth]` (player-DPT-ratio curve, bumped slightly so fights run a touch longer). **Attack** gets an ADDITIVE per-floor step bonus `ENEMY_ATTACK_FLOOR_BONUS[node.depth]` (≈ +1 every 2 floors, top +4 — steepened 2026-06-23 so enemy damage outruns the now-deterministic player HP growth; see [`docs/balance-combat-math.md`](../balance-combat-math.md) §7.1) on top of the authored base — attack is the lethality knob (it drives skull-match damage AND now enemy SKILLS, which carry `scaling`), so it ramps as small additive steps (preserving per-enemy identity) rather than a multiplier. A per-enemy **`attackScale`** (default 1) scales that floor bonus for designed exceptions (0 = opt out). **Tiering is by base value + role** (minions authored ~12-18, elites ~24-28) and floor-gating. Sim-derived budgets live in `sim/`; see [`docs/balance-findings.md`](../balance-findings.md). **(Enemy skills scale too — see decision #34/#35: enemy damage/armor skills carry `scaling: { attack }`, so they grow with the floor-scaled attack.)**
