# Decision #44 — Enemies show their relics as "PASSIVES" in the skills pane, not in a relic bar (players unchanged).

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Enemies show their relics as "PASSIVES" in the skills pane, not in a relic bar (players unchanged).** For ENEMIES ONLY, the relic bar is retired as a display: an enemy's relics are rendered as passive cards at the TOP of the enemy [`SkillsPane`](../../src/js/ui/SkillsPane.js), before its skills (see the mock). The player relic bar is untouched.
- **Passive card** ([`skillCard.js`](../../src/js/ui/skillCard.js) `measurePassiveCardModel`/`drawPassiveCardModel`): same `skills_button` frame + circular icon + keyword description as a skill card, but a two-region layout — a HEADER row (a purple `ui_skill_panel_passive_banner` sprite from `ui_spritesheet_character_pane`, with the word "Passive" drawn onto it, + the relic name auto-shrunk to one line) over a BODY row (relic icon + wrapped keyword description) — and an "infinite" (∞) badge in place of the mana-cost pill (same `COST_BADGE_*` pill size/shape). It reuses `createCardModel(relic)` (the relic's name/description/effects/icon map straight onto the model's `skill` field) and the shared `resolveModelDynamics` helper so `<<n>>` dynamic values resolve live from the enemy's stats (fed via `SkillsPane.setOwnerStats`).
- **Wiring** ([`SkillsPane.js`](../../src/js/ui/SkillsPane.js) `setPassives(relics)`): idempotent by relic-id signature (returns true on change); combines `passives → skills → ghost fillers` via `_rebuildRows` (passive rows persist across `setSkills`). Passive rows are never castable (guarded in `handleMouseUp`). [`BattleScene`](../../src/js/ui/BattleScene.js) calls `_enemySkillsPane.setPassives(state.enemyState.relics)` every frame in `updateFromController` (was `_enemyRelicBar.setRelics(...)`); on change it re-runs `_registerSkillTooltips()` so the passive descriptions' `[[keyword]]` spans get keyword tooltips like skills. Transform (Phoenix→Egg) works automatically since it reads live `state.enemyState.relics`.
- **The enemy `RelicBar` element is kept but never populated** — it stays in `mainRow` as empty layout spacing that mirrors the player relic bar's width, so the board remains centered/symmetric. (Its `setTooltipManager`/`handlePageClick`/`triggerJiggle`/`setAssetManager` hooks are harmless no-ops on an empty bar; enemy passive cards do NOT jiggle on trigger.)
