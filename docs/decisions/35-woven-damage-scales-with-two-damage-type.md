# Decision #35 — Woven (Skill Weave) damage scales, with two damage TYPE tags, a Greater amplifier, and live <<n>> descriptions.

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Woven (Skill Weave) damage scales, with two damage TYPE tags, a Greater amplifier, and live `<<n>>` descriptions.** Builds on decision #34's scaling system inside the synthesizer ([`skillSynthesizer.js`](../../src/js/data/skillSynthesizer.js)):
- **Two damage tags replace the old `damage` tag** ([`skillWeaveTags.js`](../../src/js/data/skillWeaveTags.js)): **`strike`** (a damaging spell that scales with Attack) and **`blast`** (a damaging spell that scales with Magic) — renamed from the old `physical`/`magical` for clarity vs. the `attack`/`magic` stat-gain tags. The synthesizer's shared `emitDamage(type, amount)` rolls a **scaling MULTIPLIER preset** (`rollDamageScalingPreset` → a key of `DAMAGE_SCALING_PRESETS` in [`scalingConfig.js`](../../src/js/data/scalingConfig.js): `_33`=×1/3 … `_300`=×3, weighted by `weaveConfig.DAMAGE_SCALING_WEIGHTS` — bigger = rarer = a lucky high-roll), sets `scaling: { [stat]: mult }` on the effect, and writes `Deal <<amount>> [[phys]]/[[mag]]` so the card shows the LIVE computed value (decision #34's `<<n>>`).
- **Cost rises with the multiplier, non-linearly:** the scaling adds POWER (→ cost) via `DAMAGE_SCALING_POWER` (estStat × perScaledPoint × a random `luck` factor), so a big multiplier can occasionally land under-priced.
- **`greater` tag** (a MODIFIER): multiplies ANY magnitude verb's output — Create / Strike / Blast / Attack / Magic / Armor / Heal / Drain (`greaterBoost`, always ≥ +1; `GREATER_CONFIG.damageMult`/`createMult`) — OR widens an **area destruction** (3x3 → 5x5) when there's no magnitude verb; AND may **surge** (`surgeChance`) an extra synergistic effect (re-introduces a controlled "weave surge", gated by the tag; drawn from `SYNERGY_BY_ACTION`, recorded in `injectedTags`). Unused Greater → a wasted-tag reason.
- **Cost-color skew (req 5):** when no element tag dictates the cost color (the `rollCostColor` fallback — "without influence"), Strike gradients red→…→purple and Blast purple→…→red via `weaveConfig.DAMAGE_COLOR_SKEW`.
- **Icon:** `strike`/`blast` rank like the old `damage` in [`spellIconRecipe.js`](../../src/js/icons/spellIconRecipe.js) `EFFECT_TAG_PRIORITY` and alias to the `foreground_damage` sprite (`EFFECT_SPRITE_ALIAS`). **Tune:** preset odds (`DAMAGE_SCALING_WEIGHTS`), scaling cost (`DAMAGE_SCALING_POWER`), Greater (`GREATER_CONFIG`), skew (`DAMAGE_COLOR_SKEW`) — all in [`weaveConfig.js`](../../src/js/data/weaveConfig.js).
