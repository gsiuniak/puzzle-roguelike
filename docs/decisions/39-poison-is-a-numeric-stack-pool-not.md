# Decision #39 — Poison is a numeric STACK pool (the Witch Doctor's identity), NOT a duration status.

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Poison is a numeric STACK pool (the Witch Doctor's identity), NOT a duration status.** Poison lives as `state.poison` (an integer count, added in [`BattleController._cloneState`](../../src/js/game/BattleController.js), runtime-only, starts at 0) — deliberately separate from the duration-based status system (`state.statuses`) because its lifetime model is stacks+halving, not turn cycles.
- **Tick model.** At the END of the APPLIER's turn the poisoned side takes damage equal to the current stack count, then the stacks are **halved** (floor). Implemented in [`BattleController._tickPoison(targetSide)`](../../src/js/game/BattleController.js): routes through `this.resolver.applyDamage` so the hit is **NOT armor-piercing** — the poisoned side's barrier → armor → block absorb it like any other damage (dropped the old direct-to-hp pierce to curb scaling); sets `_defeated` on a kill, emits a green floating `-N` (of the actual post-absorption damage), then `poison = floor(poison/2)` even if armor ate the hit. Called from [`_endTurn(side)`](../../src/js/game/BattleController.js) for the side's OPPONENT (the side ending its turn applied the poison), with a `_checkGameOver` re-check since poison can be lethal. Mirrors the Egg-invulnerability guard. Extra turns extend the same turn, so poison ticks once when control actually passes (not per extra-turn).
- **Application scales (halved); tick is flat.** A skill applies poison via the new **`apply_poison`** effect (`{ effectType:'apply_poison', poison:{ amount, scaling?, target?, perSkull? } }`, [`MatchResolver` SKILL_EFFECT_TYPES](../../src/js/game/MatchResolver.js)) resolved in [`BattleController._resolveEffect`](../../src/js/game/BattleController.js) → `_applyPoison(targetState, base + perSkull*boardSkulls + scaledBonus(scaling, caster))`. Stacks applied scale with the caster's stat at a deliberately LOW rate (Poison Dart: Magic `_25`; woven poison halves its rolled preset) — the halving decay already ≈ doubles each stack's lifetime value, so the half-rate scaling keeps poison's effective scaling in line with direct damage rather than doubling it; the per-tick DAMAGE is always flat = stack count.
- **Relic path (Poison Vial).** The relic [`poison_vial`](../../src/js/data/relics/relicCatalog.js) (Witch Doctor starter) is an `onDealDamage` passive `{ effectType:'apply_poison', poison:{ requireSkull:true } }` — host-handled (EffectResolver doesn't know `apply_poison`, so PassiveSystem forwards to [`_handlePassiveBoardEffect`](../../src/js/game/BattleController.js) → `_applyPassivePoison`), applying poison = `floor(payload.amount × fraction)` (the damage just dealt × a tunable `fraction`, **0.5** for Poison Vial) to the damaged side. Gated on `payload.isSkull`, a new flag added to the `onDealDamage` payload by [`_dispatchDamageEvent`](../../src/js/game/BattleController.js) (4th `opts` arg) and set `true` at the two SKULL-damage dispatch sites (`_doRemove`, `_executeDestroyTiles`). So only skull damage poisons; skill/bleed/echo damage does not.
- **Witch Doctor kit.** [`witchDoctor.js`](../../src/js/data/characters/witchDoctor.js) now runs `skills:['summon_dead','poison_dart']` + `relics:['poison_vial']` (Oungan/heal and Evil Eye removed). **Summon Dead** ([`skillCatalog.js`](../../src/js/data/skills/skillCatalog.js)) is a MASS `convert_tiles_by_type` green→skull (3 purple, non-targeted) — converts all Green into Skulls (which feed Poison Vial when matched), a "tend vs reap" tension with Poison Dart (which makes Green). (The earlier single-tile `convert_tile` variant is kept commented out in the entry for reference.) **Poison Dart** (5 green) applies `<<2>>` Poison (Magic `_25`), creates 3 green (self-fuel), and grants `<<4>>` Barrier (Magic `_66`, the non-heal defense). Icon + SFX `skill_poison_dart` (sprite in `ui_spritesheet_player_skills`, clip in the SFX sprite + SoundConfig), relic icon `relic_poison_vial` (in `ui_spritesheet_relics`).
- **Rendering (PLACEHOLDER).** Poison damage floats as a green `-N` ([`BattleScene`](../../src/js/ui/BattleScene.js) `STAT_TEXT_STYLE.poison`, kind `'poison'` emitted by `_tickPoison` via `_emitFloatingStat`). The current stack count shows as a small green number near the portrait top ([`CharacterInfoPane._renderPoisonBadge`](../../src/js/ui/CharacterInfoPane.js), reads `state.poison` in `updateFromState`; `POISON_BADGE_*` consts). A proper status-style overlay is deferred. The `[[Poison]]` keyword is in [`keywordDefinitions.js`](../../src/js/data/keywordDefinitions.js).
- **Spell-synth integration (currently DISABLED).** The **`poison`** weave tag carries `disabled: true` ([`skillWeaveTags.js`](../../src/js/data/skillWeaveTags.js)), so it's dropped from `DRAWABLE_TAG_IDS` (never offered in a draw) AND from the synthesizer's `NON_COLOR_BONUS_TAGS` (never created by `random`/greater-surge). ALL poison machinery below is LEFT INTACT (dead for the weave, but Poison Dart + Poison Vial still work) — remove the `disabled` flag to re-enable woven poison. When enabled: the `poison` tag (ACTION, UNCOMMON) is the green counterpart to `strike`/`blast`: [`skillSynthesizer.js`](../../src/js/data/skillSynthesizer.js) `emitPoison` rolls a SMALL base stack count ([`weaveConfig.js`](../../src/js/data/weaveConfig.js) `TAG_VALUE_TABLES.poison`, EV ≈ 3 — smaller than the damage roll since stacks ≈ 2× over the decay tail) + a Magic scaling MULTIPLIER preset (like blast) **halved** (`POISON_SCALING_FACTOR` 0.5, since the decay tail already doubles each stack), emits `apply_poison` with `Apply <<n>> [[Poison]]`. Priced via `POWER.perPoisonStack` (**2.0** — the real ~2× value, so woven poison costs accordingly). Its **preferred cost color is green** (`ACTION_COST_AFFINITY.poison`), it's amplified by **`greater`** (`greaterBoost`), and **`skull + poison`** adds a `perSkull` rider CAPPED at 1 (vs strike/blast's possible 2; resolved in `_resolveEffect`'s APPLY_POISON case). Wired into name/suffix pools, `SYNERGY_BY_ACTION`, the generic SFX fallback (damage family), `emitRandomBonus`, `EFFECT_RESOLUTION_ORDER` (52), and the spell-icon recipe ([`spellIconRecipe.js`](../../src/js/icons/spellIconRecipe.js): priority 94, `foreground_damage` alias). `scalablePayload` ([`scalingConfig.js`](../../src/js/data/scalingConfig.js)) recognizes `apply_poison` so the woven `<<n>>` resolves live.
