# Decision #33 — Spell icons for woven skills are COMPOSITED at runtime from authored spritesheet layers, deterministic per spell.

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Spell icons for woven skills are COMPOSITED at runtime from authored spritesheet layers, deterministic per spell.** No procedural drawing — the icon is a blend stack of pre-painted sprites. See §4.8 for the three-module breakdown ([`spellIconRecipe.js`](../../src/js/icons/spellIconRecipe.js) layer selection / [`spellIconCompositor.js`](../../src/js/icons/spellIconCompositor.js) blend rendering / [`spellIcons.js`](../../src/js/icons/spellIcons.js) cache+integration). The non-negotiables: (a) the layer stack + blend order is the format — base orb (source-over) → optional minor effect (MULTIPLY, embeds) → major effect (COLOR-DODGE, the readable subject) → `icon_border_2` (reset to source-over, never blended); bump `ICON_PIPELINE_VERSION` (now **3**) if it changes; (b) zero randomness — the same `(tags, cost, spellId)` resolve to the same plan and pixels (variant picks are a deterministic hash, not RNG); (c) selection is NAME-DRIVEN: base color from the skill's `cost` (dominant mana color), effect sprites from the spell's tags ranked by `EFFECT_TAG_PRIORITY` — so the two source sheets MUST use semantic sprite names (`<color>_base[_n]`, `foreground_<tag>[_n]`, `icon_border_2`); a sheet packed with opaque `sprite_N` names resolves to blanks. Generated canvases register into AssetManager via `registerCanvas(key, canvas)`, keyed `spell_icon_<hash>`. Caches (module-level Map, keyed `plan.signature`+`ICON_PIPELINE_VERSION`) clear in `MapScene.resetForNewRun()`. The icon is built in `SkillWeaveScene._finishWeave` (passing `keywords` + the synthesized `cost`), displayed in the scene's RESULT phase, rides the `onComplete` payload, and is set as `skill.icon = icon.assetKey` (SkillButton renders it unchanged). To add a base color or effect sprite: add the named sprite to the matching sheet — no code change. The previous fully-procedural pipeline (FBM clouds / gradient-map LUT / `pngGlyphs.js` / `ui_spritesheet_weave_grayscale`) was REMOVED. Dev grid: `src/icon-debug.html` (loads both sheets via its own AssetManager); selection tests: `node sim/test-spell-icon-recipe.mjs`.
