# Decision #36 — Post-victory growth is AUTO-applied per character via a per-victory growthPlan — stat PICKING DISABLED (updated 2026-06-23).

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Post-victory growth is AUTO-applied per character via a per-victory `growthPlan` — stat PICKING DISABLED (updated 2026-06-23).** **SUPERSEDED:** the player-chosen Level Up overlay described below is **no longer shown** — it was a mathematically dominated pick (always Max HP; see [`docs/balance-dominant-strategy-analysis.md`](../balance-dominant-strategy-analysis.md) + [`docs/balance-combat-math.md`](../balance-combat-math.md)). Each character now grows on a fixed `growthPlan` field on its def (Warrior `{maxHp:5, startingAttack:1}`, Mage & Witch Doctor `{maxHp:4, startingMagic:1}`), AUTO-applied by [`BattleScene._applyGrowthPlan`](../../src/js/ui/BattleScene.js) on victory (fallback `DEFAULT_GROWTH_PLAN`); the victory flow is now `GAME_OVER → (auto growth) → RewardOverlay → MapScene`. The [`LevelUpOverlay`](../../src/js/ui/LevelUpOverlay.js) + `LEVEL_UP_*` tables are kept DORMANT (re-enable by calling `_showLevelUpOverlay()` on victory). The original (now-dormant) overlay description follows for reference: The victory post-battle flow was `GAME_OVER → LevelUpOverlay → RewardOverlay → MapScene` (defeat still routes straight to GameOverScene; decision #27). [`LevelUpOverlay`](../../src/js/ui/LevelUpOverlay.js) is a modal styled like RewardOverlay (BattleScene paints the dark backdrop + renders it in `renderForeground`, routes input while active, gates tooltips/corner-buttons). It shows three attribute cards — **Attack / Magic / Max HP** — each with a reused glowing stat icon (`icon_attack` / `icon_magic` / `character_select_heart`) and `current → upgraded`; the pick is **mandatory** (no skip, ESC ignored) and always grants growth. Wiring in [`BattleScene`](../../src/js/ui/BattleScene.js): on victory `_showLevelUpOverlay()` builds the cards from `getEffectivePlayerStats(runState)` + `LEVEL_UP_GROWTH` (`{ attack:1, magic:1, maxHp:6 }`, tunable); `onAttributeSelected` → `_applyLevelUp(key)` (`applyRunModifier` on `LEVEL_UP_STAT_PATH`, bumps `runState.victories`); `onDismiss` → `_showRewardOverlay()` (generates the relic options, same as before). The old `_applyVictoryGrowth` auto-growth is **no longer called** (kept dormant). **Handoff:** the Level Up panel plays a quick fade+shrink EXIT (`OVERLAY_EXIT_DURATION`); on completion (in `update`) it fires `onDismiss` → the RewardOverlay fades+GROWS in (`OVERLAY_ENTER_FROM_SCALE`, no slide). The dark backdrop stays STEADY across the handoff (both `getBackdropAlpha` return full while active, no re-ramp) so only the panels crossfade — no backdrop flicker. Sprites: `ui_spritesheet_level_up_screen_elements` (`ui_level_up_container_panel` / `_attribute_panel` / `_flair_left` / `_flair_right`), registered in [`main.js`](../../src/js/main.js) SPRITESHEET_MAP.
