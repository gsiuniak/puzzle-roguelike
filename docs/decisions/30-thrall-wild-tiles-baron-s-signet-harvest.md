# Decision #30 — Thrall wild tiles + Baron's Signet harvest are fully data-driven (the Act 1 boss engine).

> Extracted verbatim from CLAUDE.md §7 (2026-07-14 split). Historical record — reflects the design at time of writing.

**Thrall wild tiles + Baron's Signet harvest are fully data-driven (the Act 1 boss engine).** A wild tile type (`THRALL`, `isWild`) and two enemy relics replace Lord Malakor's old mana-flood engine. The mechanic reuses existing extension points — no one-off boss checks:
- **Wild matching** lives entirely in `BoardModel._scanLineRuns` (shared by `findAllMatches` + `findAllConnectedMatches`). A Thrall substitutes for any concrete color/skull on a line (not for inert Disease); a match still resolves to the concrete type, so `MatchResolver.analyzeMatches` awards that type's mana/skull damage unchanged. A Thrall destroyed with no host awards nothing (`isMana` excludes wild). Player swaps validate through the same `analyzeMatches` precheck, so swapping a Thrall into a line "just works".
- **Wild visual indicator** = the `wild_tile_border` frame image overlaid on top of the Thrall tile art by `BoardPlaceholder._drawWildTileBorder` (the base sprite is untouched), centered and scaled slightly larger than the cell (`WILD_TILE_BORDER_SCALE`) so it encompasses the tile. It's purely render-time and data-driven by `isWild(tileId)`, so it appears/vanishes automatically with the tile's wild state and follows fall/swap animation; drawn in a deferred pass after all tiles (so the overhanging frame isn't clipped by neighbors), under the highlight/hover/selection overlays. The old animated rainbow border (`_drawWildBorder` + `WILD_BORDER_CONFIG`/`WILD_BORDER_HUES`) is disabled but kept as a fallback if the asset is missing.
- **Create (Baron's Signet)** = `create_tiles` board passive with `avoidMatches:true`, fired at the owner's **`onTurnEnd`**. `BattleController._applyPassiveCreateTiles` places tiles one-at-a-time, each preferring a spot where `BoardModel.positionCreatesMatch` is false (re-checked per placement, graceful fallback to any replaceable tile), so fresh Thralls don't auto-resolve into free matches. Seeding at turn END (before the player's turn) gives the player a turn to spend the Thralls. When Thralls are placed this way, `_applyPassiveCreateTiles` sets the one-shot `_thrallSummoned` flag (surfaced via `getState().thrallSummoned`) so BattleScene plays the `sfx_thrall_summon` SFX once.
- **Harvest (Usurper's Heart)** = `harvest_tiles` board passive, fired at the owner's **`onTurnStart`**. `BattleController._applyPassiveHarvest` counts all Thralls the player left behind, grants the owner `attackPer` attack each (permanent, same semantics as `gain_attack`), converts them to Skulls in place (no cascade — the Skulls sit as a threat), and queues a one-shot `harvestEvents` entry (Thrall positions captured BEFORE conversion + tendril color).
- **Pre-action animation:** the harvest fires at the boss's `onTurnStart` (before it acts). `_applyPassiveHarvest` adds `HARVEST_ANIM_DELAY` to `_extraEnemyTurnDelay` (reset each turn intro before the onTurnStart dispatch, consumed when the enemy fires), so the boss waits while `BattleScene._spawnHarvestTendrils` plays [`HarvestTendrilEffect`](../../src/js/ui/HarvestTendrilEffect.js) — continuous red energy tendrils staying connected from each harvested Thrall to the enemy portrait (pulses flow along them toward him). (The board mutation itself is synchronous — the data applies at turn start while the tendrils play; a fully animation-gated apply would need async turn machinery, deliberately avoided.)
- **Harvest feedback:** `_spawnHarvestTendrils` also plays the `sfx_thrall_harvest` SFX (once per harvest event) and spawns a dramatic [`BloodSplashEffect`](../../src/js/ui/BloodSplashEffect.js) (opaque liquid blood, scaled to cell size) at each harvested Thrall's location, alongside the tendrils.
- **Timing/ordering:** Baron's Signet fires `onTurnEnd` (seed 3 Thralls), Usurper's Heart fires `onTurnStart` (harvest leftovers) — different triggers, so Malakor's `relics` array order is irrelevant. The split (create at the boss's turn END, harvest at his NEXT turn START) puts a full PLAYER turn between the two, so the player can spend Thralls for their own matches before the boss reaps whatever remains. Tunables: relic payloads (`createTiles.amount`, `harvestTiles.attackPer`/`toType`/`tendrilColor`), `HARVEST_ANIM_DELAY`, and `HarvestTendrilEffect` ctor config.
